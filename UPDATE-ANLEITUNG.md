# GRWM 2.0 – Update auf GitHub Pages

1. ZIP auf dem Smartphone entpacken.
2. Im GitHub-Repository `kenshi787/grwm-app` auf **Add file → Upload files** gehen.
3. **Alle Dateien aus diesem Ordner** hochladen, nicht die ZIP-Datei. Vorhandene Dateien mit gleichem Namen werden ersetzt.
4. **Commit changes** bestätigen.
5. Unter **Settings → Pages** bleibt `main` / `(root)` eingestellt. Veröffentlichung abwarten.
6. GRWM in Chrome neu laden. Falls noch die alte Version angezeigt wird: Chrome schließen, Seite erneut laden oder unter App-Info den Cache (nicht die Daten!) löschen.

**Vorher in der bisherigen GRWM-App unter Einstellungen unbedingt ein Backup exportieren.** Nicht Browser-/App-Daten löschen oder die App deinstallieren, solange kein Backup geprüft wurde.

Neu: mehr Kategorien, Herz direkt am Bild, Raster-/Listenansicht, Begrüßung, lokaler Profilname und Stiltyp, vier Schriftarten, Outfit-Kalender mit In-App-Wasch-Check, Outfit-Freigabe-Vormerkung (noch keine Online-Freundesfunktion).

**Noch nicht implementiert:** Online-Anmeldung/Freunde, tatsächliche Freigabe zwischen Geräten, KI-Bilderkennung, automatische Hintergrundentfernung, Push-Benachrichtigungen, eigenes Sternlogo. Diese Funktionen erfordern weitere Entwicklung und teils zusätzliche Dienste/Berechtigungen.
