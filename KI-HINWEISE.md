# GRWM 2.1 – KI Fotostudio (Beta)

- In „Neu“ ein Foto wählen und optional „Foto erkennen“ oder „Hintergrund entfernen“ drücken.
- Die Funktionen laden externe JavaScript-Bibliotheken und KI-Modelle herunter. Dafür wird Internet benötigt. Die Bildverarbeitung erfolgt im Browser. Bibliotheksanbieter/CDNs sehen technische Abrufdaten.
- Fotoerkennung liefert einen **Kategorie-Vorschlag**, keine garantierte Erkennung. Marke, Größe und Farbe bleiben manuell.
- Hintergrundentfernung kann auf Mobilgeräten aufgrund von Arbeitsspeicher, Verbindungsproblemen oder Browser-Unterstützung scheitern.
- Beim Speichern wird das freigestellte Bild übernommen; das Original wird separat gespeichert. Beim Backup werden beide Fotos exportiert.
- Vor einem Update in GRWM ein Backup exportieren. Bei GitHub alle Dateien im Repo-Hauptverzeichnis ersetzen.
- Die App wurde statisch und auf JS-Syntax geprüft, nicht live auf Samsung getestet.
